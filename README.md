# Diagnosis AI Project

Diagnosis AI Project is a web-based platform developed for doctors to assist in the patient diagnosis process through the integration of machine learning and artificial intelligence. The platform is designed to speed up clinical decision-making while improving diagnostic accuracy and workflow efficiency.

The system uses a **Feedforward Neural Network (FNN)** machine learning model for **disease detection**, analyzing patient symptoms and medical inputs to predict the most likely disease. Alongside this, an **AI-powered medical assistant** provides **personalized diagnostic support** by considering important patient-specific factors such as **age and gender**, enabling more relevant and context-aware diagnostic suggestions.

## Features

* **FNN-based Disease Detection** for accurate disease prediction from patient symptoms.
* **AI Medical Assistant** that assists doctors during diagnosis.
* **Personalized Diagnosis** based on patient age and gender.
* **Faster Clinical Workflow** by reducing the time required for preliminary diagnosis.
* **Doctor-Friendly Web Interface** for efficient patient evaluation and decision support.

The goal of the project is not to replace medical professionals, but to provide intelligent assistance that helps doctors diagnose patients more quickly, consistently, and accurately, ultimately improving patient care outcomes.
